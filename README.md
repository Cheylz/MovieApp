# Movies App

Android-приложение на Kotlin и Jetpack Compose, которое загружает данные из интернета. Учебный проект, **в разработке**.

Сейчас приложение показывает тестовые посты с публичного API [JSONPlaceholder](https://jsonplaceholder.typicode.com). Дальше планирую перейти на реальные данные о фильмах.

## Что уже умеет
- Загружать список из сети через Retrofit
- Показывать три состояния экрана: загрузка, список, ошибка
- Различать ошибки сети (нет интернета) и ошибки сервера (код ответа) и показывать понятные сообщения
- Повторять загрузку по кнопке «Повторить»
- Не перезапускать загрузку и не терять данные при повороте экрана

## Планы
- [ ] Вынести загрузку данных в отдельный слой (Repository)
- [ ] Перейти на API фильмов (TMDB) с названиями, рейтингом и постерами
- [ ] Загрузка картинок через Coil
- [ ] Экран подробностей фильма (Navigation 3)
- [ ] Кэш в базе данных (Room), чтобы список открывался без интернета
- [ ] Внедрение зависимостей (Hilt)

## Технологии

## Как запустить
1. Склонировать репозиторий
2. Открыть проект в Android Studio
3. Запустить на эмуляторе или телефоне (нужен интернет)
